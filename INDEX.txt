📊 WHAT YOU'LL GET - OUTPUT FORMAT

After running the scraper, you'll receive a CSV file with:

✅ Game Information
   • title - Game name
   • game_url - Direct link to game page
   • jam_rate_url - Jam rating/submission page
   • tags - All game tags (comma-separated)

✅ Developer Information
   • developer - Studio/developer name
   • developer_url - Profile on itch.io

✅ Contact Information
   • email - Contact email address
   • twitter - Twitter/X profile URL
   • discord - Discord server/profile link
   • website - Personal or studio website
   • other_links - Additional contact links

───────────────────────────────────────────────────────────────────
🎮 3D GAME DETECTION - HOW IT WORKS
───────────────────────────────────────────────────────────────────

The scraper identifies 3D games by checking for:

✅ Direct indicators
   • Tags: "3D", "3d"

✅ Engine tags
   • Unity, Unreal, Godot

✅ Perspective tags
   • First-Person, Third-Person, FPS, TPS

✅ Style tags
   • Low Poly, Voxel, 3D Platformer

✅ Text analysis
   • Title/description contains "3D"

Decision: Game is marked as 3D if ANY indicator matches.
