🚀 QUICK START - SOLUTION 1 (QUICK PAGE SCRAPER)
═══════════════════════════════════════════════════════════════════════════════

📄 Output: brackeys_3d_games.csv

Features:
• Multi-criteria 3D detection (tags, engines, perspectives)
• Contact extraction (email, social, website)

• Single or batch page processing

────────────────────────────────────────────────────────────────────────────────

  python3 brackeys_master_scraper.py --task 1    # Page 1
  python3 brackeys_master_scraper.py --task 2    # Page 2
  python3 brackeys_master_scraper.py --task 3    # Page 3

  python3 contact_augmentation.py brackeys_master.csv
  python3 google_sheet_creator.py brackeys_master_augmented.csv

Automated workflows:
  python3 complete_workflow.py --pilot-only      # Tasks 1-3 only
  python3 complete_workflow.py --skip-full-scrape # Tasks 1-6, skip task 4
  python3 complete_workflow.py                   # All tasks
